# ucd

The Unicode Character Database 17.0.0 files `cmd/gen` reads, as published
at https://www.unicode.org/Public/17.0.0/ucd/ (`emoji-data.txt` from its
`emoji/` directory, `DerivedBinaryProperties.txt` from `extracted/`).
They are unmodified.
